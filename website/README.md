# Website Leni Heaf

Statische Website (HTML, CSS, JavaScript), läuft ohne Build-Schritt auf jedem Hosting
(z. B. Netlify, Vercel, GitHub Pages, IONOS, Strato).

**Ansehen:** `index.html` im Browser öffnen.

## Vor dem Livegang

- [ ] **Bilder ersetzen:** Alle Fotos sind Platzhalter (picsum.photos). Stellen sind im Code mit `TODO` markiert.
- [ ] **Referenzprojekte:** Die vier Karten unter „Ausgewählte Arbeiten“ durch echte Projekte ersetzen.
- [ ] **Impressum & Datenschutz:** Seiten anlegen und in Footer und Formular verlinken (Pflicht in Deutschland).
- [ ] **Schrift lokal hosten:** Geist herunterladen (https://vercel.com/font) und per `@font-face` einbinden statt Google Fonts (DSGVO).
- [ ] **E-Mail-Adresse** `hallo@leniheaf.de` anpassen (in `index.html` und `script.js`).
- [ ] **Formular:** Öffnet aktuell das E-Mail-Programm. Für direkten Versand z. B. Formspree oder Netlify Forms anbinden.
- [ ] **Social-Links** im Footer auf deine Profile setzen.
